# WatchMyVideo

Просматривайте свои видео прямо в браузере — без сервера, без регистрации и без загрузки файлов в сеть. Полностью статический сайт на чистом HTML/CSS/JS: его можно открыть как GitHub Pages или просто запустить из любой папки на диске.

**Сайт:** https://flare-award.github.io/WatchMyVideo/

## Три режима оформления

Переключатель в правом верхнем углу (на мобильных — в верхней панели). Выбор сохраняется в `localStorage`.

| Режим | Что это |
|---|---|
| **Плеер** | Минимализм: только плеер, без шапки и боковых панелей. Панель загрузки появляется по наведению. |
| **YouTube** | Похоже на настоящую страницу просмотра YouTube: лайк/дизлайк, счётчик просмотров, кнопка «Поделиться», подписка на канал WatchMyVideo, блок описания, комментарии и правая колонка «Похожие видео». Работает режим кинотеатра — плеер растягивается на всю ширину, как на YouTube. |
| **TikTok** | Полноэкранная вертикальная «лента» 9:16: правый рейл действий (аватар автора с кнопкой «+», лайк, комментарии через выезжающую панель, «В избранное», «Поделиться»), слева внизу — автор и описание, строка музыки, тонкий прогресс. Видео вписывается в кадр 9:16 и **никогда не растягивается**: 1:1 и 4:3 смотрятся хорошо, 16:9 показывается с полями сверху и снизу. |

В режимах «Плеер» и «TikTok» верхней шапки нет совсем; кнопка «Открыть» и переключатель режимов прячутся при бездействии курсора и появляются при его движении.

## Возможности

- Открытие видеофайлов (MP4, WebM, MOV, MKV, AVI) через кнопку или перетаскиванием (drag & drop) в любое место страницы
- Демо-видео в один клик (Big Buck Bunny, Blender Foundation — нужен доступ в интернет)
- Кастомные контролы без нативного `<video controls>`, автоскрытие панели управления при бездействии (~1,6 с), двойной тап по краям для перемотки ±10 с с индикатором
- Режим кинотеатра (иконка плёнки в панели), полноэкранный режим с сохранением кастомной панели
- Перемотка стрелками ←/→ (±5 с) и J/L (±10 с), клавиши 0–9 (переход к 0–90% длительности), Home/End
- **Клавиатурные сочетания не зависят от раскладки** — используются физические коды клавиш (`e.code`), поэтому `,`/`.` работают как на русской раскладке («Б»/«Ю»), а `J`/`L` — как «О»/«Д»
- Скорость воспроизведения 0.25x–2x + произвольная, сохранение высоты тона при изменении скорости
- Зацикливание видео, покадровая перемотка на паузе (`,` / `.`)
- Субтитры: загрузка `.srt` / `.vtt`, отображение поверх видео, переключение клавишей `C`
- Громкость: отдельный слайдер, отключение звука (`M`), усиление до 200% (Web Audio API, +6 дБ) — работает и на русской и на английской раскладке
- Картинка в картинке (PiP), демо-режим «Смотреть снова» после окончания видео
- Несколько файлов одного и того же видео в разном качестве: качество добавляется через «Добавить файл другого качества» — разрешение определяется автоматически, переключение без перезагрузки страницы
- Лайки, сохранение в избранное, подписка и комментарии хранятся локально в браузере (`localStorage`) и общие для YouTube- и TikTok-оформления
- Тост-уведомления вместо `alert`, понятная обработка ошибок (нет файла, нет сети, неподдерживаемый формат)
- Иконка сайта (favicon), тёмная тема

Файлы никуда не отправляются — всё декодируется и воспроизводится локально в браузере.

## Горячие клавиши

Работают при любой раскладке клавиатуры.

| Клавиша | Действие |
|---|---|
| `K` / `Space` | Пауза / воспроизведение |
| `←` / `→` | ±5 секунд |
| `J` / `L` | ∓10 секунд |
| `0`–`9` | Переход к 0%–90% видео |
| `Home` / `End` | В начало / в конец |
| `↑` / `↓` | Громкость ±5% |
| `M` | Выключить / включить звук |
| `F` | Полноэкранный режим |
| `T` | Режим кинотеатра |
| `C` | Субтитры вкл/выкл |
| `P` | Картинка в картинке |
| `,` / `.` | Предыдущий / следующий кадр (на паузе) |
| `Esc` | Закрыть панель комментариев / меню настроек (в полноэкранном режиме — выход из него) |

## Развёртывание (GitHub Pages)

Сайт не требует сборки: ветка публикуется как есть.

1. В репозитории: **Settings → Pages**.
2. **Source**: Deploy from a branch → ветка `main` (или `arena/73538011-watchmyvideo` для предпросмотра), папка `/ (root)`.
3. Через минуту сайт доступен по адресу `https://<владелец>.github.io/WatchMyVideo/`.

Работает также при простом открытии `index.html` из файловой системы, но демо-видео и переход по прямой ссылке требуют сеть.
