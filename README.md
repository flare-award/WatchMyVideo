# WatchMyVideo

Локальный видеоплеер в стиле YouTube (с переключением в стиль TikTok для вертикальных видео). Полностью статический сайт: чистый HTML/CSS/JS, без сборки и без зависимостей — иконки FontAwesome подключаются с CDN.

## Запуск

Просто откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Возможности

- Открытие видеофайлов (MP4, WebM, MOV, MKV, AVI) через кнопку или перетаскиванием (drag & drop) в любое место страницы
- Демо-видео в один клик
- YouTube-подобный интерфейс: кастомные контролы без нативного `<video controls>`, автоскрытие поверх видео, режим кинотеатра, полноэкранный режим с сохранением кастомной панели
- TikTok-режим: вертикальный кадр 9:16, боковая панель действий (лайк с сохранением в `localStorage`, поделиться через Web Share API / буфер обмена, вращающийся диск дорожки)
- Перемотка стрелками ←/→ (±5 сек) и J/L (±10 сек), клавиши 0–9 (переход к 0–90% длительности), Home/End
- Скорость воспроизведения 0.25x–2x + произвольная, сохранение высоты тона при изменении скорости
- Зацикливание видео, покадровая перемотка на паузе (`,` / `.`)
- Субтитры: загрузка `.srt` / `.vtt`, отображение поверх видео, переключение клавишей `C`
- Усиление звука до 200% (Web Audio API), отдельный регулятор громкости
- Картинка в картинке (PiP), демо-режим «Смотреть снова» после окончания видео
- Несколько файлов одного и того же видео в разном качестве: качество добавляется через «Добавить файл другого качества» — разрешение определяется автоматически, переключение без перезагрузки страницы
- Тост-уведомления вместо `alert`, понятная обработка ошибок (нет файла, нет сети, неподдерживаемый формат)

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `K` / `Space` | Пауза / воспроизведение |
| `←` / `→` | ±5 секунд |
| `J` / `L` | ∓10 секунд |
| `0`–`9` | Переход к 0%–90% видео |
| `Home` / `End` | В начало / в конец |
| `↑` / `↓` | Громкость ±5% |
| `M` | Выключить / включить звук |
| `F` | Полноэкранный режим |
| `T` | Режим кинотеатра |
| `C` | Субтитры вкл/выкл |
| `P` | Картинка в картинке |
| `,` / `.` | Предыдущий / следующий кадр (на паузе) |
| `Esc` | Закрыть меню настроек (в полноэкранном режиме — выход из него) |
